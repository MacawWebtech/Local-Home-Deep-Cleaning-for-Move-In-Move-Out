# ClearNest — Complete Website

Extract this ZIP, then open `index.html` in your browser. Use the navigation dropdowns to access both homepages and all service resources. The customer dashboard and account pages are linked in the footer.

This package contains all 18 requested pages, local CSS/JS, JPG imagery, comparison diagrams, Bootstrap 5 grid CSS, sitemap, robots rules and documentation.

Detailed setup, editing and integration notes: `documentation/README.md`.
Performed checks and verification limits: `documentation/VALIDATION.md`.

Booking, profiles, enquiries, addresses and dashboard records are stored on this device. Secure online authentication, real booking availability, payments and message delivery require backend integrations.
